# Agent Note: 用于分支 Session 与文本写作的 Loom 界面

Status: implemented

[English](2026-10-18-loom-interface.md) | 中文

## 问题

沿用 janus 的 Loom 思路，Loom 将模型输出视为一棵树：生成多个续写，查看它们，保留其中一个，同时留存其余结果。dsh 的 fork 已经把精确的事件前缀复制到独立 Session，但扁平列表和线性对话隐藏了这种关系。继承的工作掩盖了分支自身的成本，重复标题掩盖了其身份，而继续不同的回答或工具结果需要手动重建上下文。

分支探索也会成倍增加模型调用和文件系统活动。它需要明确的隔离、预算、备选结果保留和输入归属，而不能只展示多个回答却不保留各自的生成依据。

## 决定

Loom 是默认关闭的实验性可选组合包，提供 L1–L27 能力和独立的文本写作模式 Weave。发布包负责可复用的 fork、对话、搜索、循环和提供方改动；实验性包负责 Loom 行为及可忽略的 `plugin:loom/*` 记录。[Loom README](../../../../packages/experimental/loom/README.zh.md) 负责配置和 Remote 细节。

### 家族与定位

Loom 分支是通过 `SessionController.fork` 创建的顶层 fork Session。`forkLineage` 独立于可见 Chat 窗口提供精确切点和列表提示。Chat 将整个继承前缀折叠在带有 `conversation.chat.fork-cut` 的一行之后，其中包括被切点中断的 turn 及其合成收尾事件。这些行仍可由浏览器搜索和焦点发现，轨道导航会展开它们。页眉面包屑沿完整祖先链显示。自身／继承的用量和活动采用同一切点；自身缓存比例和 fork 模式 subagent 的 token 指标排除继承工作。

浏览器通过共享的 `forkFamily()` 逻辑推导可见家族；Host 为没有 Session 列表的调用方提供同样的读取。兄弟会话先按创建时间、再按 Session id 排序。侧栏中的家族相邻关系优先于各会话的固定和手动位置，但不继承固定成员资格。只有根可拖动，显示数量阈值保留完整的可见家族，父会话缺失或隐藏时，其可见子会话成为根。稳定的 fork 身份只装饰显示标题，不进入重命名草稿。fork 的自动标题使用自身符合条件的人类提示；自身手动重命名保持固定，继承的重命名则不会固定标题。

Multiverse 使用明确的自身／继承范围和家族 Session id；普通侧栏搜索保持默认行为。所有权独立于 current、shadowed 或 log-only 分类，因此新写入的继承内容替换属于自身工作。扫描和 SQLite 提供方在排序和结果数量限制之前按所有权和 id 过滤。APG 大纲、书面键盘提示和共享 BottomSheet 使家族与兄弟动作在手机宽度下无需悬停即可使用。

启用可选的 Loom 组合包会让现有 Session 查询提供方使用首次搜索时打开的内存索引，因此多重宇宙内容搜索可在随附的 Web 配置档中工作。未启用 Loom 的 base 和 Web 配置档保留关闭内容搜索的默认设置。

`requestAt` 定位到所选 seq 或之前最近一次已结算的请求，包括失败尝试。它重建提供方投影之前由循环构造的请求，包含有界的消息预览和完整系统文本，不声称复现提供方专属序列化。阅读窗格仍是已加载 turn 的摘要；折叠的推理显示最终回答步骤，其 token 计数则覆盖整个 turn。

### 分支准入与工作区所有权

每个分支集合在请求时固定精确的事件切点。重新生成和编辑重复由人类开启的 turn；引导和变体保留所选的完整前缀。编辑只改变文本，保留已存储的图片／文件引用。重新生成或编辑 fork 的首个自身 turn 时，在父会话切点创建兄弟会话，并默认采用该 fork 实际使用的自身路由，包括尚未被 header 消费的显式选择。父会话被删除时，子会话改为从所指向的 Session 分支。重定向到仍存在的父会话时，除所指向的 Session 外，还需要对该父会话拥有访问权限。显式路由覆盖从不保存全局默认值；可用性由 Session Controller 逐个子会话验证。

准入在各集合间延迟执行并采用 FIFO，同时受并发和共享文件夹写入门控限制。被文件夹阻塞的子会话不会阻塞后方符合条件的子会话。Loom 清除继承的下一 turn 输入，记录分支成员关系，应用 Host 准备，然后发送带有持久发起者归属的索引子提示。普通 Branch 动作保留其排队输入行为。名额持续到整个 Agent 空闲；子会话运行期间新增的提示会延长占用。保留期内，请求身份按所指向的 Session 去重。拆除会撤回排队工作并等待准入完成；已经存在的集合返回其已取消子会话，`gateway/cancelled` 则表示没有已准入集合。

运行条带对每个集合 id 只保留一个条目，包括启动尚未返回时发现的集合。它跟随条目变化，并对无法发出 Session 变化的等待中空闲集合重试状态读取；取消操作撤回的排队子会话少于预期时，会刷新集合。即使 Session 尚不存在，行文本或位置也能标识子会话。除编辑并分支会打开子会话外，分支操作保持源会话打开；标记属于 Session，不属于某个翻页器 turn。

worktree 隔离需要对应服务、Git 仓库和 workspace-write 策略。Loom 与其提供方共享隔离的 worktrees 组，因此可与独立 Worktree 组合包按任意顺序共同加载。集合在首次准入时捕获 HEAD 加未提交的已跟踪变更，排除未跟踪文件。隔离子会话绕过文件夹门控；仓库修改仍串行执行。Git 读取和修改采用子会话自身的执行策略，Compare 恢复冷子会话时也如此。

Compare 通过配置的模式从自身命令输出推导测试结果，绝不使用展示元数据，并结合 diff 事实、自身用量、耗时、标记和采用状态。采用操作记录所选子会话，停止并归档兄弟会话，绝不删除 Session，并报告部分归档进度以便安全重试。应用操作向干净的源工作目录写入未暂存补丁，拒绝已跟踪文件的脏变更和冲突；丢弃操作移除隔离工作目录。二者都占用子会话的维护槽位，直到移除和隔离结束记录完成，因此唤醒的提示会等待，其他维护操作收到 busy。只移除 Loom 拥有的 worktree。明确的 worktree 已结束事实会停止陈旧 diff 读取，并区分已移除和 diff 无法读取。

### 定价与自主探索

不随包提供默认价格。经过验证的 provider/model 行分别为缓存未命中、缓存命中和输出定价；用量或价格未知时，自身精确美元金额缺省。每次自身结算都采用其记录的路由，包括失败尝试。仅 Host 使用的 token 投影在读取时应用价格，使检查点独立于部署价格。分支估算优先采用被重复的 turn，否则取可见家族自身 turn 的平均值。未定价的估算返回 token；没有依据时不返回范围。所有美元金额均为标价。

Weave 估算使用所选已记录 provider/model 上的自身文本输入用量，优先采用最近一次拼接前缀完全匹配的请求，否则明确使用不同前缀的历史依据。它取已报告用量的兄弟续写的平均值，并在两个缓存计价端点均按请求的完整输出上限计价。它绝不根据字符猜测 token 数，不把缺少历史视为零成本，也不发送提供方调用。探测和继承请求不提供依据。

Autoloom 通过仅 Host 可用的 `branchFor` 使用同一运行器，因此浏览器不能伪造其提示来源或准备操作。五个工具只操作某个 weaver 自身的集合和子会话。扩展在创建 fork 之前检查分支、深度、自身 token 和可选美元预算；美元限制要求已定价用量和估算。每个子会话在首个提示之前获得非交互权限预设，并记录 `loom` 来源。子会话不能创建独立运行。预算耗尽或用量变为未定价时，结算监视器以 hook 原因停止运行中子会话并撤回排队工作。卸载会中止读取、唤醒等待、停止所拥有的工作，并在移除监视器和状态之前等待准入及活动结束；已完成的 Session 仍可使用。

### 继续执行与工具结果反事实

空闲 Agent 只有在两个收件箱队列均为空、保留的工具调用均已有结果、最后一条对话消息为 user 或 tool 时，才能在没有新用户消息的情况下继续现有模型历史。维护占用、assistant 结尾和待完成工具会在不改变日志的情况下拒绝准入。`turn/start.continuation` 记录现有的 `MessageSource`，包括 Remote 请求身份和非所有者发起者。即使观察者立即取消，已接受的继续执行仍保留其标记；恢复后，自身请求身份对重试去重，而继承身份不会抑制 fork 的工作。两个 SDK 读取器保留该可选标记，不另增 SDK 运行时命令。

反事实编辑在所选的完整工具结果批次之后 fork，清除继承的待处理输入，并在首次继续执行的 pre-step 内、turn/start 之后和模型推导之前，写入覆盖记录及仅替换内容的事件。这保留同批其他结果以及已发布读取器的生命周期规则。Chat 更新现有工具行，同时保留调用身份、参数、时间、元数据和成功／失败分类。不完整批次在 fork 之前被拒绝；创建后的失败会指明保留的子会话，客户端提供打开该子会话的操作，而不盲目再创建一个。

### 已记录概率与文本写作

token 采集按路由显式启用。`BlockTokenLogprobs` 是现有 block-end 分片上的可选元数据，请求 header 记录请求的采集数量。不增加分片判别值或面向模型的内容块。pi-ai 将该请求的原始提供方事件与文本增量配对，只有完整 token 文本精确复现回答块时才发布采集结果。元数据缺失或格式错误时会省略采集并报告降级，包括按字节切分后无法重建的文本。思考块没有概率。采样概率为空时仍表示未知，未知备选项被省略；界面不会捏造概率或发送重新评分调用。

assistant 前缀续写是单独声明的不带工具辅助能力；循环调用、工具、工具历史、空前缀或未关闭的推理均被拒绝。精确前缀必须在提供方序列化后保持不变，否则在 I/O 之前失败。Weave 在发送之前记录解析后的路由、控制项、框架文本、消息和带作者归属的前缀片段，随后记录每个兄弟续写的完整流。它占用 Session 维护槽位，卸载时中止并等待调用结束，无法记录结算时停止兄弟发送。冷前缀采用先领跑后并发；热提示只改变调度，从不保证缓存命中。重放按请求 seq 和兄弟索引排列辅助节点，而不按完成时间排列。新建 fork Session 按创建顺序绑定重放角色；已存储和已播种的子会话保留首次调用绑定。

Weave 文本保留在 Chat 之外。持久节点保留精确的前缀片段，选择记录可在重新加载后重建所选文档。用户编辑保留未变前缀的归属，并把已编辑后缀标记为人类文本。采集的备选项引用来源节点和 token 索引；不完整 token 会失去采集，而不声称精确匹配。预览不是选择。每个已记录请求，包括未选择的集合和祖先集合，都保持可选，每个模型块都可重新打开其兄弟续写。按 Session 保存的客户端状态在视图重新挂载后保留未提交文本、光标、路由和控制项；它是草稿，不是另一份持久文档。

探测在深度、累积概率和请求限制内探索已记录的单 token 备选项。已记录的采样位置区分未探测位置与已采样但没有保留备选项的位置。图中按父节点嵌套累积概率面积，并提供完整尺寸的书面路径选择器。残余表示未显示的概率质量，包括返回的最高概率 token 之外的备选项；空白不表示零概率。概率显示使用书面数值和非颜色提示，并与普通 Markdown 回答及推理分开展示。

筛选计量只对当前 Weave 选择累计已完成兄弟数量的 log2；重复选择具有幂等性，替换选择会替换该集合的计量，选择顺序跟随最近选择。Session 标记、采用和探测不增加计量。导出支持一条路径、其兄弟或已保留分支，并以 JSON、文本或转义 HTML 携带来源和筛选事实。下载是不可变、仅所有者可用的 Connection 快照，受字节数、数量和存活时间限制。拆除在释放路由之前中止并等待待处理导出；迟到结果不能创建已失效的下载 URL。

## 考虑过的替代方案

**在一个 Session 内保存多条备选 assistant 消息。** `assistant/message` 不能替换 surface。独立的 fork Session 使用现有存储和生命周期保留每条续写。

**以 subagent、工作流或 Agent Teams 作为分支。** 它们隐藏的子 Session 从调用方自身的完整历史播种。Loom 需要在精确事件切点创建顶层分支，并具有独立导航和保留。

**在 agent loop 中预填充。** DeepSeek 拒绝带工具或工具历史的前缀补全，而普通循环请求携带预设工具。精确记录输入的辅助请求避免不受支持的循环操作，并使文本写作与 Chat 分离。

**新增概率分片变体或声明 Loom 事件。** 穷举流读取器和重放会拒绝新的分片变体；读取时必需的事件会使旧 Session 读取器拒绝日志。可选 block-end 元数据和可忽略的实验记录在不改变现有判别值的情况下保持读取兼容性。

**引入 canvas 图形依赖。** fork 谱系的每个节点只有一个父节点。APG 大纲无需图形渲染器即可提供键盘和屏幕阅读器导航；概率图为无法直接操作的小区域保留书面控件。

## 后果

- 组合包使 Loom 专属控件保持可选。发布行为仍包括继承 Chat 折叠及其切点座位、完整 fork 面包屑、自身／继承计数、侧栏家族和标题、限定范围搜索支持、提供方修正和显式启用的概率采集。继承折叠影响每位 Branch 用户，需要产品确认。

- 分支集合和 autoloom 预算保存在 Host 内存中。重启会丢失排队准入、状态／取消句柄和重试去重，但保留已启动的 Session 和记录。`retainedBranchSets` 默认保留 256 个已完成集合，按创建时间从旧到新逐出，从不丢弃活动工作；逐出会使请求身份过期，但不删除 Session 或 worktree。复用该身份会创建另一个集合。

- 家族缓存亲和性使用独立的根 `cacheSessionId`，真实 Session id 继续用于重放、归属和查找。压缩、标题调用和 fork 模式 subagent 请求仍以自身 Session 作为键。subagent 建立独立家族；共享缓存亲和性不保证提供方命中。

- 共享文件夹门控覆盖已准入的 Loom 子会话，不覆盖源会话、无关 Session 或后续工作。并发共享写入者可能看到彼此的修改或将其错误归属。worktree 基准捕获首次准入时的状态，而非请求时状态，省略未跟踪／忽略文件，不安装依赖，并要求存在提交。采用／归档保留 worktree，直到应用／丢弃；应用是补丁，不是合并，所携带的未提交已跟踪工作必须先提交才能应用。

- Autoloom 在扩展前检查，并在用量结算后响应，因此最后一次回答可能超出 token 或美元预算。插件挂载处的请求都会增加其 schema 所用 token。重新生成时存储文件引用的重新绑定仍是明确的真实持久化验证缺口。公开的选择解析和预先读取隔离可用性／策略仍被推迟；路由／隔离不可用通过逐个子会话反馈或类型化拒绝报告。

- 精确概率对齐会有意舍弃不受支持或按字节切分的 token 文本采集。探测结果是有界的最高概率 token 样本，不是完整模型分布。Weave 热提示、未提交浏览器草稿和下载 URL 是临时状态；持久节点、精确前缀和选择在重新加载后保留。将织就文本直接接入 Chat 继续仍不在范围内。
