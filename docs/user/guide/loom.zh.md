# 使用织机探索不同方案

[English](loom.md) | 中文

## 概述

织机将模型输出保存为树：生成不同方案、进行对比、选择方向，同时保留其他历史。Agent 任务使用聊天分支；在光标处续写散文则使用编织。可选的实验性组合包会添加织机会话标签页、多重宇宙页面，以及供模型在预算内自主探索的工具。

<a id="enable-loom"></a>
## 启用织机

请使用包含织机及其配套核心更改的 Harness 构建，并先[配置模型](providers.zh.md)和选择[工作区](index.zh.md)。已发布的 `0.2.1-rc.2` 运行时早于这些 API；不支持把织机包安装到该运行时。配套版本发布之前，请使用包含此功能的源码检出。

打开**插件**，选择**实验性插件**旁的**更多**，然后启用**织机**。打开一个会话，选择聊天旁的**织机**。该标签页提供阅读、对比和编织；侧栏会出现**多重宇宙**。织机默认关闭。

对比文件编辑结果时，请使用至少有一次提交的 Git 仓库，并为会话授予工作区写入权限。散文续写需要明确声明支持无工具助手前缀的路由；词元探索还需要模型返回词元概率。拒绝信息会指出不支持的能力，便于你选择其他路由或减少请求的候选数量。

<a id="branches"></a>
## 创建和阅读分支

聊天轮次完成后，使用以下操作探索不同方案，并保留原始对话：

| 操作 | 作用 |
|---|---|
| **重新生成** / **重新生成 ×N** | 在一个或多个新会话中重复该轮的起始提示。 |
| **分支 ×N** | 为每条引导文本开启续写；每行采样数可生成重复变体。 |
| **编辑并分支** | 在新分支中替换用户提示，保留其已存储的附件。 |
| **模型 → 更改** | 只为这些子会话覆盖模型和思考设置。 |

运行条跟踪运行中和排队的分支。取消操作会在排队的子项创建会话之前将其撤回。保留和搁置是私人的筛选标记，与反馈评分相互独立。变体翻页器和标题栏标签可切换同一切点的兄弟分支。

在**织机 → 阅读**中，选择树行即可阅读该分支。继承轮次默认折叠；展开后可查看共同前缀。自有轮次和自有词元计数将新增工作与继承工作区分开来。**模型看到了什么**展示提供方特定序列化之前的已记录请求；如有已记录的推理内容，可通过推理卡片展开查看。

聚焦树后，可使用上/下、左/右、Home/End 和 Enter。按 `g` 创建分支、`k` 保留、`x` 搁置。快捷键参考中列出了这些按键。在手机宽度下，变体标签会打开底部面板，其中显示完整标题和可见控件。

使用**多重宇宙**浏览跨会话的分支家族，并搜索自有消息、继承消息或全部历史。侧栏将分支嵌套在来源会话下；普通侧栏搜索保持原有范围。

## 对比和应用更改

开始相互竞争的文件编辑前，请选择**将每个分支隔离到工作树**。每个子会话获得该组首次获准启动时的 HEAD，以及已跟踪文件中未提交的更改。不包含未跟踪和被忽略的文件，也不会安装依赖。共享文件夹的分支访问同一批文件；依次启动并不能将其与来源会话或后续提示隔离。

打开**对比**，选择分支点，再选择一行。对比显示从该分支自有命令输出解析的测试摘要、差异统计、自有用量、耗时和标记。缺少测试摘要表示没有匹配到配置的模式，并不表示测试通过。展开行即可检查各文件的差异。

- **将差异应用到文件夹**把隔离分支的补丁复制到干净的来源检出中，并移除该工作树。来源存在已跟踪的更改或补丁冲突时会拒绝操作；请先提交或暂存来源更改，然后检查并重试。应用后的更改保持未提交状态。
- **采用**记录所选分支，停止运行中的兄弟分支并将其归档。该操作保留所有会话历史，不应用文件，也不移除工作树。
- **丢弃工作树**只移除织机创建的隔离检出；其会话历史仍可阅读。**在此继续**会在聊天中打开所选分支。

<a id="tool-result"></a>
## 尝试不同的工具结果

在已完成的工具结果上选择**编辑结果并分支**，编辑可见结果文本，然后继续。织机会创建分支，让模型回应替换文本，而不重新运行工具，也不添加用户消息。来源结果、工具参数、同批结果、耗时和成功/错误分类均保持不变。替换文本是假设性观察；继续时可根据子会话权限进一步调用工具。

<a id="weave"></a>
## 使用编织撰写散文

打开**织机 → 编织**，撰写开头、放置光标、选择局部模型和控制项，然后生成多个续写。这些调用使用准确的文本前缀，不包含聊天历史或工具，且关闭思考。可以预览候选而不更改文档；选择操作会记录其中一个，并保留所有兄弟候选。已保留请求选择器可重新打开先前的候选组。

已记录的答案概率通过底色、虚线下划线和百分比文字展示。打开一个词元即可检查候选或探索有界的词元多重宇宙，然后从所选词元继续。未捕获概率的文本和推理内容不会添加概率标注。探索器只在实际探测过的位置标出未显示的概率质量。

筛选计量器对每个当前选择累加 `log₂(N)`，其中 N 为该组已完成的编织候选数。替换选择会替换对应的计分；聊天标记和探测路径不计分。可将当前路径、其兄弟候选或已保留的散文节点导出为 HTML、文本或 JSON。分享前请检查导出内容：其中保留生成和撰写的文本、来源归属以及筛选记录。文本和 HTML 还包含完整的 JSON 记录。

<a id="autoloom"></a>
## 让模型自主探索

请模型探索两种续写、阅读两者、保留一个并归档另一个。五个工具为 `loom_expand`、`loom_wait`、`loom_read`、`loom_keep` 和 `loom_cull`。工具卡片链接真实的子会话，并显示剩余预算。组合包为子会话应用只读、非交互式的 `loom-child` 权限预设；子会话不能启动独立的探索运行。

自主工作前，请配置分支数、深度、自有词元数和可选的标价美元预算。预算超限时，扩展操作会在创建分支前拒绝；最后一次响应的结算用量仍可能使词元或美元用量超出上限。美元上限要求已配置价格，并能得到有价格的估算。

<a id="limits"></a>
## 费用、保存的数据和限制

每个分支运行其自身的模型请求。每条散文续写会产生一次辅助调用；词元探测还会产生额外的有界调用。默认不提供任何价格。未配置提供方/模型价格时，界面显示词元数，而非零美元。配置后显示的美元数是标价估算，并非账户余额或账单。共同前缀调度可能提高缓存复用，但不保证缓存命中。

会话历史、已记录的散文节点和选择会持久保存。分支队列、保留的候选组状态、自主探索预算、热前缀提示和下载 URL 位于 Host 内存中：重启后会丢失，排队的子项不会恢复。已经启动的子会话仍然可用。采用或归档不会清理工作树；请明确使用应用或丢弃操作。

织机是实验性功能。其插件记录、API 和界面不承诺稳定性；会话格式迁移只尽力保留实验性记录。请导出准备长期保留或分享的内容，并保持正常的工作区备份。
