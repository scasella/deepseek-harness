# 分支标题与侧边栏家族

[English](guide.md) | 中文

## 变更

侧边栏和聊天的 Branch 操作创建分支时，不再将继承标题重命名为带编号的用户标题。分支保留继承标题，直到收到自身第一条符合条件的人类提示词，再获得自身的回退标题与可选生成标题。继承的用户重命名不会阻止这次生成；在分支内重命名仍会固定其标题。侧边栏行显示分支标识，并将可见后代嵌套在来源之下。家族相邻优先于单行的置顶与手动位置。

## 迁移

1. 无需迁移配置或 Session 日志。已有日志标题保持完整。
2. 如果已有分支带有编号用户标题，且你想重新生成它，请使用标题提供方的显式 `ctx.sessionTitle.refresh(session)` 操作。否则保留或正常重命名即可。
3. 通过 Branch 创建分支，发送新提示词，确认标题跟随其自身提示词，且侧边栏将其放在来源之下。
